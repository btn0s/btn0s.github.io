Best Roblox Clips Publisher

The publishing tool behind the YouTube channel Best Roblox Clips.

Best Roblox Clips makes short Roblox videos: stories, challenges, rankings and troll traps. This tool is how the channel's owner publishes them.

What it does

  • Uploads the channel's own Shorts and schedules when they go public.
  • Sets each video's title, description, tags and thumbnail.
  • Adds videos to the channel's playlists.
  • Reads the channel's views and analytics to see which videos work.

It uses the YouTube API Services. Only the channel's owner signs in, and only to manage this one channel. It doesn't offer sign-in to anyone else and doesn't touch any other channel.
